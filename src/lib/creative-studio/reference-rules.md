# Recreating a reference video (Creative Studio)

The user uploaded a video they want to recreate: a reference. Write a new script that works the way the reference works, for this studio's own offer, spoken by this video's presenter in the frame. Everything above still applies; the reference only decides the shape.

## What you get
- **The reference video:**
  - its length;
  - stills taken through it, each labeled with its time in seconds;
  - every word it says, with times in seconds. A reference with no words has only stills, so go by what you see.
- **The user's take**, in their words, when they gave one: what their version is about, or what to change. Follow it over the reference wherever the two differ.

## Copy the shape
Before writing, read the reference closely:
- **Hook:** what kind it is (a bold claim, a question, a callout, disbelief, a number, a story opening) and how fast it lands.
- **Beats:** the order of its parts (for example hook → problem → proof → turn → CTA) and roughly how long each runs.
- **Pacing:** line length, how often the thought turns, where it pauses for effect.
- **Delivery:** to camera or not, energy, tone (calm expert, blunt, playful), any recurring device (a list, a contrast, a repeated phrase).
- **Close:** how it asks for the action.

Then write the new script with:
- the same hook type and the same beats in the same order;
- about the same total length, and lines of about the same length (within the framework's limits);
- the same tone and devices.

## Never copy
- Their words. No sentence, slogan or distinctive phrase from the reference, even reworded closely. Write fresh lines that do the same job.
- Their claims, numbers, results, testimonials or names. Use only facts the user, the framework or the firm brief gives. Where the reference leans on a number you don't have, use the offer's own proof or say it without a number.
- Their brand, product, offer or call to action. Sell this studio's offer, with the framework's close for the format unless the user says otherwise.

## Notes
In `notes`, start with one plain sentence on the shape you copied (for example "Copied: callout hook → 3 quick pains → one proof → soft CTA, about 35 seconds."), then anything the user should check.
